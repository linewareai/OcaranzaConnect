# LinewareAI PMS

Nueva base del panel administrativo de LinewareAI.

Esta versión reinicia la aplicación frontend desde cero y conserva únicamente la distribución general del panel: barra lateral, cabecera, navegación de módulos y adaptación móvil.

Módulos de la base:
- Inicio
- Calendario
- Reservas
- Habitaciones
- Huéspedes
- Operación
- Pedidos
- Caja
- Reportes
- Configuración

Los datos actuales son locales de demostración. La autenticación, persistencia, multi-propiedad e integraciones externas se implementarán sobre esta base, no se heredan del proyecto anterior.
